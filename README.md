# 🐍 Python 100 Programs

A beginner-friendly collection of **100 Python programs** designed to build strong programming fundamentals through simple, practical examples.

This repository covers Python basics, conditional statements, loops, functions, recursion, strings, lists, tuples, dictionaries, file handling, and other important programming concepts.

---

## 📌 About the Project

**Python 100 Programs** is a practice-based Python programming repository created for students and beginners who want to learn Python by writing and executing small programs.

Each program focuses on a specific concept and uses simple Python syntax so that it is easy to understand, modify, and run.

The main goal is to improve:

* Python programming fundamentals
* Logical thinking
* Problem-solving skills
* Understanding of programming concepts
* Practical coding experience

## ▶️ How to Run

### 1. Install Python

Download and install Python 3 on your computer.

Check the installation:

```text
python --version
```

### 2. Clone the Repository

```text
git clone https://github.com/yatharthg1727-ctrl/Python_100_Programs.git
```

### 3. Open the Project

Open the downloaded folder in **VS Code** or **PyCharm**.

### 4. Run a Program

For example:

```text
python "29_Print 1 to N.py"
```

You can run any `.py` file individually.
